# Brand assets — Start Academy

Source de vérité pour tout usage graphique dans le produit et les livrables
externes (proposition commerciale, pack communication dirigeant, exports PDF).
Extraits du brand book officiel Start Academy.

## Palette

| Rôle | Hex | Usage |
|---|---|---|
| Bleu principal | `#00527A` | Titres, blocs de mise en avant, fond sombre |
| Bleu vif | `#3EA9FF` | Accents, liens, CTAs |

## Typographie

| Rôle | Famille | Usage |
|---|---|---|
| Display | Rajdhani | Titres, chapitres, entêtes bloc |
| Body | Montserrat | Texte courant, paragraphes, légendes |

## Assets disponibles

| Fichier | Format | Usage |
|---|---|---|
| `logo.png` | PNG 21 kB | Logo standard, fond clair, web/UI |
| `logo-white.png` | PNG 21 kB | Logo blanc, fond sombre, web/UI |

| `logo-blanc-hd.pdf` | PDF 2.4 MB | Logo blanc haute définition, impression / export PDF |
| `charte-graphique.pdf` | PDF 214 kB | Brand book officiel — référence complète (palette, typo, dos et don'ts) |

## Règles

- **Ne pas modifier** les logos (couleurs, proportions, ajouts, effets).
- Palette + typo **impératives** sur tout livrable externe.
- Pour un doute (déclinaison sur fond photo, mono-couleur, etc.), consulter
  `charte-graphique.pdf` avant d'improviser.
